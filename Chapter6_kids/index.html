어린이 보호구역 특별관리 서비스 서비스 기획안

유치원 중심 동적 200m 감지 및 맞춤형 안심 알림 웹페이지 프로젝트

홈으로 인터렉티브 시뮬레이터
웹 서비스 제작 목표 안내

운전자에게 꼭 필요한 순간,
유치원 보호구역 특별 집중 알림을 제공합니다.

모든 어린이 보호구역에 동일한 경고를 남발하는 기존 지도 서비스와 달리, 초등/중학생보다 신체 및 인지 능력이 현저히 낮아 사고 위험이 극심한 '유치원 보호구역'을 대상으로 등·하교 시간대에 한정하여 반경 200m 이내 진입 시 시각적 서클 강조와 음성(TTS)으로 운전자 서행을 유도하는 맞춤형 웹 애플리케이션입니다.

GitHub 리포지토리 보러가기

핵심 차별화 포인트 (Core Differentiator)

기존 네비게이션/지도 서비스 대비 왜 유치원에 집중하는가?

경고 피로감(Alert Fatigue) 해소

모든 스쿨존에서 상시 울리는 경고는 운전자의 감각을 무디게 만듭니다. 본 서비스는 사고 위험성이 수배로 치솟는 특정 조건에서만 동작합니다.

최고 위험군 '유치원' 타겟팅

만 3~5세 유아는 차량에 대한 대피 판단 및 반응 속도가 현저히 느립니다. 일반 스쿨존보다 유치원 인근 구간을 최우선 '특별관리구간'으로 다룹니다.

시간대 동적(Dynamic) 제어

유치원 등교 시간(07:30~09:00) 및 하교 시간(12:00~16:30)에만 200m 반경 감지 시 서클 펄스와 TTS 음성 경고를 결합하여 발동합니다.

구축 웹페이지 구성 요소 및 기능 명세

아래 탭을 클릭하여 만들어지는 웹 애플리케이션의 핵심 모듈을 확인해보세요.

서비스 동작 시나리오 (User Journey)

STEP 1
GPS 수신 & 수동 핀 지정

웹 앱 실행 시 HTML5 Geolocation 좌표 수신 또는 사용자가 지도 클릭으로 차량 위치 설정

STEP 2
반경 200m 연산

Haversine 공식을 사용해 200m 범위 내 유치원 및 초등학교 보호구역 DB를 정밀 탐색

STEP 3
등하교 시간 판정

실시간 시계 또는 사용자 지정 등하교 시간대(기본 07:30~09:00, 12:00~16:30) 부합 여부 확인

STEP 4
특별관리 발동 & TTS

(200m 내 유치원 존재) & (등하교 시간) 충족 시 RED 펄스 강조, 경고 배너 및 음성 안내 출력

F-1. 위치 엔진 (Location Engine)

HTML5 Geolocation 실시간 위치 수신 및 지도 클릭을 통한 운전자 위치 수동 재설정 지원.

F-2. 200m 공간 탐색 (Spatial Search)

Haversine 공식을 활용한 $d \le 200\text{m}$ 구역 필터링 및 반투명 서클 오버레이 표시.

F-3. 실시간 디지털 시계 위젯

지도 우측 상단 Glassmorphism 시계 배치. 등하교 시간 해당 시 [특별관리시간] 붉은색 뱃지 노출.

F-4. 사용자 맞춤 시간 관리

등교/하교 시간을 사용자 맞춤으로 직접 설정 가능하며 LocalStorage에 영구 보관.

F-5. 특별관리구간 하라이트 & 배너

조건 충족 시 지도 펄스 애니메이션 적용 및 화면 상단 시선집중형 위험 경고 배너 팝업.

F-6. Web Speech API 기반 TTS 음성 안내

한국어 음성 "현재 어린이 통행이 많은 시간입니다. 속도를 줄여 운전하세요." 자동/토글 출력.
